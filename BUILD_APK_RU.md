# PDF Architect Ultra — получение устанавливаемого APK

**Важное ограничение:** в этом архиве находятся исходники версии 0.4.0-alpha, а не готовый APK. Для APK требуется Android SDK и компилятор Android Gradle. Эти инструменты недоступны в среде подготовки проекта, поэтому сборка здесь не выполнялась.

## Вариант 1 — GitHub Actions (без локального Android Studio)

1. Создайте **приватный** репозиторий GitHub. Загрузите в него **содержимое** папки `PdfArchitectUltra`, обязательно вместе со скрытой `.github/workflows/build-debug-apk.yml`.
2. В репозитории откройте **Actions → Android Debug APK → Run workflow**. Если появляется предложение включить workflows, включите их для своего репозитория.
3. После *успешного* запуска выберите внизу **Artifacts → PDF-Architect-Ultra-debug-apk** и скачайте ZIP.
4. Внутри будет `app-debug.apk`. Перенесите его на Samsung Galaxy S24 Ultra; откройте через **Мои файлы**. При необходимости разрешите установку приложений из выбранного источника и проверьте предупреждения системы.
5. Откройте приложение → **Попробовать на демо-чертежах**. Проверьте перо, маркер, измерения и экспорт.

**Примечание:** GitHub Actions требует интернет для загрузки Android SDK / Gradle / Maven. Если сборка завершилась с ошибкой, APK не создастся; текст ошибки находится в логах запуска.

## Вариант 2 — Android Studio

1. Установите Android Studio + Android SDK API 36 и JDK 17. Распакуйте архив на компьютер.
2. Откройте **File → Open → PdfArchitectUltra**. Дождитесь разрешения Gradle-зависимостей.
3. Проект содержит `gradle-wrapper.properties`, но **не** содержит исполняемые `gradlew` / `gradle-wrapper.jar`. При необходимости установите Gradle 8.13 и выполните `gradle wrapper --gradle-version 8.13`.
4. Выполните в терминале корня проекта:

   `gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug`

5. При успешной сборке APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Для публикации в Google Play потребуется полноценная release-сборка, ключ подписи, политика конфиденциальности и тестирование безопасности/совместимости.

## Что проверить на Samsung Galaxy S24 Ultra

- Запуск и открытие демо PDF, затем настоящего документа через **Мои файлы → Открыть с помощью → PDF Architect Ultra**.
- Перо S Pen, маркер, ластик, Undo/Redo, переключатель `S Pen`.
- Калибровка 5 м → линейка → многоугольная площадь в м².
- Русский и иврит в текстовых заметках, вставка изображения.
- Экспорт копии PDF и открытие её в другом просмотрщике. Проверьте, что исходные текст и векторные линии сохранились.
- Перезагрузка приложения и восстановление локальных пометок по ранее выбранному PDF.
- Работа с PDF с 0°/90°/180°/270° поворотом и крупными сканами; отметьте возможные баги рендера и памяти.

Изменение **уже подписанного** PDF обычно делает прежнюю цифровую подпись недействительной; экспортируйте отдельно и проверьте подписи снова.
