# PDF Architect Ultra 0.4.0-alpha — статус сборки

**Готового `app-debug.apk` в архиве нет.** Исходники проверены и подготовлены к CI, но собрать и проверить Android APK в данной среде невозможно: отсутствуют Android SDK и Gradle, загрузка внешних зависимостей недоступна.

## Что проверено здесь

- Kotlin/JVM smoke-тесты пройдены: расстояние, площадь, повороты/смещения PDF-страницы, проверка экспорта страницы только с полигоном площади.
- Исправлена логика сохраняющего экспорта: страницы только с измеренной площадью теперь включаются в PDF.
- XML AndroidManifest/resources корректно разбираются.
- Встроенный Engineering_Demo.pdf читается и содержит 3 страницы.
- **Не проверено**: Android-компиляция, запуск на телефоне, S Pen и фактический PDF-экспорт.

## Как получить APK без Android Studio

1. Распакуйте этот архив. Создайте **private** репозиторий на GitHub.
2. Загрузите содержимое папки `PdfArchitectUltra` в корень репозитория, **включая скрытую `.github`**.
3. Откройте GitHub → репозиторий → `Actions` → `Android Debug APK` → `Run workflow` и подтвердите запуск. При загрузке файлов в ветку `main` сборка может запуститься автоматически.
4. После зелёного статуса сборки нажмите на завершённый запуск и скачайте `Artifacts` → `PDF-Architect-Ultra-debug-apk`.
5. Распакуйте загруженный с GitHub ZIP: файл `app-debug.apk` можно установить на Samsung Galaxy S24 Ultra.

Если GitHub показывает красную ошибку, APK **не** создан; сохраните лог из шага `Build installable debug APK` для исправления.

Подробнее: `BUILD_APK_RU.md`.
